# Piloto externo de Code Timeline

Buscamos cinco desarrolladores que usen Claude Code o Codex durante una semana.
La pregunta no es si la interfaz gusta: es si el historial evita trabajo real.

## Protocolo

1. Instala y vincula un repositorio de trabajo.
2. Trabaja normalmente durante cinco sesiones o siete días.
3. Cada vez que consultes una entrada anterior, registra el resultado:
   - `encontrada`: sí/no;
   - `evito_reinvestigar`: sí/no;
   - minutos que habrías empleado reconstruyendo el motivo;
   - si la entrada seguía concordando con el código.
4. Al terminar, comparte solo métricas agregadas; nunca código ni explicaciones privadas.

## Criterio de éxito

El piloto valida el producto si al menos tres de cinco personas vuelven a una
entrada antigua y al menos dos declaran una recuperación que evitó
reinvestigación. Entradas creadas, clics y tiempo en pantalla no cuentan como
valor por sí solos.
