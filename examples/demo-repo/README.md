# Repo de ejemplo — Carrito

Un módulo de carrito minúsculo (dos archivos, sin dependencias) que existe
solo para que Code Timeline tenga algo real que enseñar.

`scripts/seed-demo.mjs` vincula esta carpeta como proyecto y le registra un
puñado de cambios de ejemplo, con su antes/después y su explicación. Como la
vista a pantalla completa lee el archivo COMPLETO del disco en vivo, estos
archivos tienen que existir de verdad — no son un pegote en un JSON.

No es código de producción de nada. Cámbialo, rómpelo, bórralo.
